# 📡 Security Telemetry

> Security telemetry is the data generated by systems, applications, networks, identities, cloud platforms, and security controls that enables defenders to observe and investigate activity.

Without useful telemetry, a SOC cannot reliably detect or investigate threats.

---

# 1. Telemetry vs Log

These terms are related but not identical.

### Log

A recorded event or message generated by a system.

Example:

```text
User login failed
```

### Telemetry

A broader collection of security-relevant observations.

Telemetry can include:

```text
Logs
Process Events
Network Connections
DNS Requests
File Activity
Authentication Events
Endpoint Activity
Cloud Events
Packet Data
```

Think of:

> **Logs as one type of telemetry.**

---

# 2. Why Telemetry Matters

SOC analysts need telemetry to answer:

```text
What happened?
Who performed it?
When did it happen?
Where did it happen?
How did it happen?
What happened before?
What happened afterward?
What was affected?
```

Telemetry provides the evidence.

# 12. Telemetry Quality

More telemetry does not automatically mean better security.

Important characteristics include:

### Coverage

Are important assets producing telemetry?

### Quality

Is the data accurate?

### Completeness

Are important fields available?

### Timeliness

How quickly is telemetry available?

### Retention

How long is it stored?

### Integrity

Can analysts trust the data?

### Cost

Is collection economically sustainable?

---

# 13. Telemetry Gaps

A telemetry gap occurs when useful security information is unavailable.

Example:

```text
Attack occurs
     ↓
Endpoint has no process logging
     ↓
SOC sees network connection
     ↓
Cannot determine executing process
     ↓
Investigation limited
```

Telemetry gaps can directly affect detection and investigation.

---

# 14. Example — PowerShell Investigation

Suppose a suspicious PowerShell command executes.

Useful telemetry may include:

```text
Process Creation
Parent Process
Command Line
User
Hostname
Timestamp
Network Connection
File Creation
```

Correlation:

```text
WINWORD.EXE
      ↓
powershell.exe
      ↓
Encoded Command
      ↓
Network Connection
```

This provides much stronger evidence than a single event.

---

# 15. Telemetry and Detection

Detection depends on available telemetry.

Example:

```text
Threat Behavior:
PowerShell execution
       ↓
Required Telemetry:
Process Creation
       ↓
Detection:
powershell.exe
       +
suspicious command line
```

If the required telemetry does not exist, the detection may fail.

# 16. Telemetry and MITRE ATT&CK

```text

   ↓

   ↓

```

This creates a relationship between:

```text
Attack

Detection
Response
```
